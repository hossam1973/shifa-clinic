# شفاء — منصة إدارة العيادة

تطبيق ويب عربي (RTL) للأطباء يعمل على الكمبيوتر والجوال.

## المزايا
- **لوحة اليوم:** المواعيد وحالاتها، دخل الشهر، الفواتير غير المدفوعة، زيارات آخر 7 أيام.
- **المرضى:** ملف طبي (الحساسية، الأمراض المزمنة، العلامات الحيوية، سجل الزيارات).
- **المواعيد:** حجز مع منع التعارض، وتتبع الحالة (محجوز ← انتظار ← كشف ← تم).
- **الوصفات:** وصفة برأس العيادة مع تنبيه الحساسية ونسخ النص.
- **الفواتير والإعدادات.**
- **31 حاسبة سريرية في 10 تخصصات:** NIHSS، Hunt & Hess، ICH، mRS، GCS، CKD-EPI 2021، Cockcroft-Gault، الصوديوم والكالسيوم المصحح، فجوة الأنيون ونسبة دلتا، CURB-65، Wells، BODE، تدرج A-a، STOP-BANG، Child-Pugh، MELD-Na، Ranson، Rockall، D-dimer المعدّل للعمر، ISS، HbA1c، BMI/BSA، ACR/EULAR 2010 RA و2015 Gout، qSOFA، SOFA، APACHE II، CHA₂DS₂-VASc، HAS-BLED، QTc.

## التشغيل
ملف واحد بلا خطوات بناء: افتح `index.html` في المتصفح، أو انشره عبر GitHub Pages.

## ملاحظات
- البيانات تُحفظ حالياً في متصفح الجهاز (localStorage) فقط، ولا يوجد خادم أو تسجيل دخول.
- الحاسبات أداة مساعدة لاتخاذ القرار ولا تغني عن التقييم السريري.
