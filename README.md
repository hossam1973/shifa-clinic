# شفاء — منصة إدارة العيادة

تطبيق ويب عربي (RTL) للأطباء، يعمل على الكمبيوتر والجوال، ويمكن **تثبيته كتطبيق** (PWA) والعمل به **دون إنترنت**.

## المزايا
- **لوحة اليوم:** المواعيد وحالاتها، دخل الشهر، الفواتير غير المدفوعة، زيارات آخر 7 أيام.
- **المرضى:** ملف طبي (الحساسية، الأمراض المزمنة، العلامات الحيوية، سجل الزيارات).
- **المواعيد:** حجز مع منع التعارض، وتتبع الحالة (محجوز ← انتظار ← كشف ← تم).
- **الوصفات:** وصفة برأس العيادة، تنبيه الحساسية، **طباعة** ونسخ النص.
- **الفواتير والإعدادات.**
- **نسخ احتياطي:** تصدير البيانات إلى ملف JSON واستيرادها على أي جهاز.
- **47 حاسبة سريرية في 11 تخصصاً**، لكل منها تفسير ومرجع علمي.

## التشغيل
لا يحتاج خطوات بناء. لتشغيله محلياً (مطلوب خادم حتى يعمل وضع عدم الاتصال):
```bash
npm start
```
ثم افتح http://localhost:8080. للنشر: أي استضافة ملفات ثابتة (GitHub Pages، Netlify، Cloudflare Pages).

## الاختبارات
```bash
npm test
```
اختبارات بقيم معروفة لكل المعادلات (Node 18+). تعمل تلقائياً على GitHub Actions عند كل push.

## هيكل المشروع
```
index.html              هيكل الصفحة
css/app.css             التصميم (فاتح/داكن + طباعة)
js/calculators.js       مكتبة الحاسبات (بلا DOM، قابلة للاختبار)
js/app.js               واجهة التطبيق والتوجيه والتخزين
sw.js                   Service Worker للعمل دون اتصال
manifest.webmanifest    بيانات تثبيت التطبيق
tests/                  اختبارات الحاسبات
```
لإضافة حاسبة: أضف تعريفها إلى مصفوفة `CALCS` في `js/calculators.js` واكتب لها اختباراً. عند كل إصدار غيّر `VERSION` في `sw.js`.

## ملاحظات
- البيانات تُحفظ في متصفح الجهاز (localStorage) فقط؛ لا يوجد خادم أو تسجيل دخول بعد.
- الحاسبات أداة مساعدة لاتخاذ القرار ولا تغني عن التقييم السريري.
